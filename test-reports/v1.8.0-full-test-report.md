- **82 项项目问题**（`project_audit`：硬编码路径、CSS 变量）

### 4.2 A11y 违规
`browser_a11y_check` 发现 4 项 WCAG 违规：
- `heading-order`：标题层级跳跃
- `link-in-text-block`：链接与文本块对比度不足
- `region`：页面缺少 region 语义
- `select-name`：select 元素缺少可访问名称

### 4.3 安全风险
- `security_headers_check`：0/7 安全头部缺失 + Server 信息泄露（nginx/1.27.5）
- `security_csp_analyze`：无 CSP 配置
- `security_owasp_top10`：A5 fail（安全配置错误）
